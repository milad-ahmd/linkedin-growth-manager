## 📦 Install

**One command (installs the whole collection):**

```bash
curl -fsSL https://raw.githubusercontent.com/milad-ahmd/agent-skills/main/install.sh | bash -s -- linkedin-growth-manager
```

**Manually (Claude Code):**

```bash
git clone https://github.com/milad-ahmd/linkedin-growth-manager /tmp/linkedin-growth-manager
mkdir -p ~/.claude/skills && cp -r /tmp/linkedin-growth-manager/skills/linkedin-growth-manager ~/.claude/skills/
```

**Per project:** copy `skills/linkedin-growth-manager` into `<project>/.claude/skills/`.
**Any other agent:** paste [`SKILL.md`](skills/linkedin-growth-manager/SKILL.md) into your rules or system prompt.
